## 2. Description of the Game & Local P2P Connectivity
Quoridor P2P is a tactical board game that allows players to play locally via pass-and-play or peer-to-peer (P2P) Wi-Fi connections with nearby devices. 
* **No Server Storage:** All game sessions, moves, and local communications occur directly between connected local peers. We do not operate central game servers that store your personal gameplay data.
* **Network Permissions:** The app uses Wi-Fi and local network state permissions solely to facilitate peer-to-peer discovery and connection between players in the same physical space.
